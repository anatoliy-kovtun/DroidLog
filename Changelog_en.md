# Changelog

## v2.1
- Disabled automatic opening of the main menu when a macro is enabled.

## v2.0
- Added the ability to export logs and archives to a TSV file for further analysis in spreadsheet applications such as Google Sheets.
- Added the ability to delete all archives using a menu button (Menu -> Clear log -> Delete archives).
- Added a confirmation dialog for clearing the log.

## v1.2
- Added the ability to launch the main macro menu without creating a shortcut (via Action Test / Test Macro).
- Refactored code to simplify future editing and maintenance.
- Improved UI layout and visual consistency.

## v1.1
- Replaced gzip-based log archiving with plain text archive files.
