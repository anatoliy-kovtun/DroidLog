# Історія змін (Changelog)

## v2.1
- Відключено відкриття головного меню при ввімкненні макросу

## v2.0
- Додана можливість експортувати лог і архіви в TSV файл для подальшого аналізу в табличних процесорах таких як google sheets.
- Додана можливість видалити всі архіви кнопкою в меню (Меню -> Очистити лог -> Видалити архіви)
- Доданий діалог запиту підтвердження очистки логу

## v1.2
- Додана можливість запускати головне меню макросу без створення ярлика (через Тест дій / Тестувати макрос).
- Проведено рефакторинг коду для спрощення подальшого редагування та підтримки.
- Покращено вигляд інтерфейсу користувача (UI).

## v1.1
- Замінено архівування gzip на архівування у прості текстові файли.
